# CHANGELOG

All notable changes to the Memorae AI Second Brain will be documented in this file.

## [0.1.0] - 2026-11-15
### Added
- Initial project scaffolding with Next.js 14 App Router, TypeScript, and Tailwind CSS.
- Mobile-first Android PWA shell with bottom navigation (`Home`, `AI Assistant`, `Tasks`, `Memory`, `Profile`) and floating Quick Capture.
- Complete Supabase PostgreSQL schema with `pgvector`, Row Level Security (RLS) isolation, tasks, persistent reminders, and long-term memories.
- Universal AI Provider abstraction layer (OpenAI, NVIDIA NIM, Gemini) supporting English, Hindi, and Hinglish intent extraction.
- Permanent project continuity documentation suite (`AGENTS.md`, `ARCHITECTURE.md`, `DATABASE_SCHEMA.md`, `API_DOCUMENTATION.md`, `ENVIRONMENT_SETUP.md`, `DEPLOYMENT_GUIDE.md`, `TESTING_GUIDE.md`).
